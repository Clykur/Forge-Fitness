Build a modern, premium, high-conversion fitness studio website using Next.js (App Router), Tailwind CSS, and Framer Motion.

Goal:
The website should feel like a ₹5L+ agency-built product — clean, bold, high-performance, mobile-first, and designed to convert visitors into bookings.

Brand Context:
- Fitness Studio based in Bangalore, India
- Target: young professionals (18–40), premium clients
- Tone: energetic, elite, minimal, powerful

Design Requirements:
- Use high-quality images from Pexels (fitness, gym, trainers, transformations)
- Dark theme with neon accents (black, deep gray, electric green/blue)
- Large bold typography (use Google Fonts like Inter / Sora / Space Grotesk)
- Smooth animations using Framer Motion
- Glassmorphism + subtle gradients
- Avoid boxed card-heavy layouts — use clean sections with spacing
